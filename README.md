# DIYAutoDrone
This drone is being created to allow me to learn ROS2 basics, as well as to demonstrate my electrical/systems engineering skills. 

This drone, planned to be built on a 7inch frame, will use a rasberry pi 5 4GB, an iflight BLITZ H7 PRO, and a camera to fly. It will also be controllable via my Steam Deck, also running ROS2. 

Initially this drone will run with an off the shelf flight controller and ESC, but evenually I will replace these with custom alternatives to prove my electrical engineering and board design skills.
